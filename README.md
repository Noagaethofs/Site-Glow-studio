# Glow Studio — site vitrine

Site statique (HTML / CSS / JS, sans dépendance) : ouvrez `index.html` dans un navigateur.

- `index.html` — contenu de la page
- `css/style.css` — styles & animations
- `js/main.js` — intro, fond dérivant, menu, apparitions, onglets, chatbot FAQ
- `assets/` — logo (clair / sombre) et favicon

## À personnaliser
- Email `contact@glowstudio.be` (index.html + `EMAIL` dans js/main.js)
- Lien Instagram (`https://instagram.com/`)
- Prix des offres (actuellement « Sur devis »)
- Vidéo de fond du hero (bloc commenté dans index.html)
